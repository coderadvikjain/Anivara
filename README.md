## What Is Anivara TV?

Anivara TV brings discovery, playback, and personal watch organization into one
streamlined interface. The platform combines a responsive player with curated
content browsing, account authentication, watch history, and saved titles.

## Features

| Discovery | Playback |
| --- | --- |
| Trending and popular content | Responsive widescreen player |
| Genre-based browsing and filtering | Multiple streaming nodes |
| Content shuffle | Latency monitoring and fallback handling |

| Personalization | Platform |
| --- | --- |
| Persistent watch history | Google and Discord authentication |
| Wishlist and saved state | Responsive desktop and mobile navigation |
| Episode progress tracking | Administrative user and referral metrics |
